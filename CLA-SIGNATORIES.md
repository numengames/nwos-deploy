# CLA signatories

Each row is a signature of [CLA.md](CLA.md), added by its author in their
own commit (their first PR includes this edit). CI checks pull request
authors against the **GitHub user** column.

**Agent accounts.** Rows marked _agent_ are not third-party signatures. An
agent has no legal personality and cannot make the representations in
CLA.md §4; it is an instrument operated by Numen Games S.L., so copyright in
its contributions vests in Numen directly and there is no grant to receive.
The row exists because CI gates on authorship, and it records the natural
person accountable for that account's contributions — not a licence Numen
grants itself. If an agent account ever contributes work whose rights do not
already belong to Numen, that work needs a signature from whoever holds them.
