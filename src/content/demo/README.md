# Faro Austral — NWOS workspace

This is the **public example** of what the paid trial writes. Faro Austral
is an invented organisation: a 24-person marine engineering cooperative in
Vigo. No real client's workspace is ever shown here.

A real workspace is a private repository with this same structure, written
from what is public about your organisation.

```
canon/      the four founding documents the trial writes
decisions/  one file per decision taken, with its date and its reason
missions/   work in progress: what is being done, by whom, and when it closes
reports/    what happened, written to be read by people who were not there
agents/     the AI agents of the organisation: what each may do, and what it must ask
```

Everything is plain text. Nothing is locked in: if you leave, it all goes
with you.
